# 需求基线

## 目标
macOS 升级 Antigravity 后，一键重新应用兼容的汉化补丁；不能用旧版完整归档覆盖新版。

## 用户可见行为
提供 check/apply/restore 命令与双击 .command 入口。按文件哈希判断兼容性；不匹配则停止。保留新版版本号、全部无关文件和外置资源标记。应用前保存原始归档和清单，恢复时核对版本与当前安装哈希。

## 验收标准
兼容新版本成功；未知修改、混合汉化、损坏归档、损坏备份、跨版本恢复、运行中应用、并发写入全部拒绝。重复应用无副作用。所有补丁 JS 先做语法检查。真实客户端只执行检查；部署回归在隔离的应用副本上完成。

## 约束与范围
不启动上游 HTTP 服务、不强杀进程、不禁用更新、不清除隔离属性、不改签名、不联网执行脚本、不改旧入口。使用 Node.js 内置模块，无安装期 npm 依赖。首次版本聚焦 macOS，命令行接受明确的自定义应用路径以便测试。

## 假设与问题
采用用户已确认的一键恢复方案；不增加自动后台任务。GitHub fork/push 需设备登录；本地工作不依赖登录。旧手动汉化没有本工具备份时检查为已汉化，但恢复要求本工具的有效记录。
