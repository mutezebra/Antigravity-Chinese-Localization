# macOS 升级后安全重装汉化

在 macOS 上，优先使用仓库根目录的 **macOS安全汉化.command**。双击后选择检查、重新汉化或恢复英文。需要 Node.js 18 或更新版本；终端启动方式不受 Finder 的脚本权限提示影响。

```bash
# 只检查，不关闭或修改应用
node macos-reapply.js check

# 保存工作并手动退出 Antigravity 后安装
node macos-reapply.js apply

# 请求正常退出，安装成功后重新打开；不会强杀进程
node macos-reapply.js apply --quit --launch

# 恢复由本工具保存的同版本原包
node macos-reapply.js restore --quit --launch
```

默认目标为 `/Applications/Antigravity.app`。可用 `--app '/path/to/Antigravity.app'` 指定其他安装；可用 `--state-dir '/path/to/backups'` 指定备份根目录。使用自定义备份目录后，应用和恢复操作必须传入同一个目录。目录不能放在应用包内，也不能经过符号链接。

## 升级后怎样处理

1. 保留官方更新功能。
2. 更新后若恢复英文，运行检查或双击入口。
3. 受补丁影响的原始文件全部匹配时，工具只替换这些文件，并保留当前版本的其余内容。
4. 对应文件发生变化、混合汉化、资源缺失或保护状态无法确定时，停止并提示；等待维护者更新补丁指纹与翻译后再运行。

本工具不承诺所有未来版本都兼容，也没有后台监控或自动下载执行代码。更新 fork 的源码与补丁资源后需再次检查。

## 适配与边界

当前指纹清单来自上游 `b39779adc8fd40004888885b2fe0006d5f6b94a0` 的 2.31.0 汉化包，覆盖 14 个原始文件，已在 2.31.2 原始归档副本上验证应用和恢复。翻译资源复用 `extracted/`，其内容必须与 `patches/safe-reapply.json` 中的哈希一致；不会执行 `extracted/` 中的程序。

- 不覆盖成旧版本的整个 `app.asar`，不改 `package.json` 版本号。
- 不使用上游控制中心，不监听端口，不运行 `npx` 或 shell 拼接命令。
- 更新归档条目偏移与完整性哈希，保留外置资源标记；资源须存在且匹配。
- CLI 应用前核对应用版本和 Electron fuse；保护开启或格式未知则停止，不改签名、fuse、Info.plist 或隔离属性。
- 请求退出可能触发应用的保存/退出确认。未退出会停下，不强杀。
- 修改应用归档会影响原厂代码签名。不同 macOS/企业策略可能拒绝启动；本工具不绕过系统策略，遇到限制请恢复原包或重新安装官方客户端。
- 归档内符号链接、超大归档、非标准版本号目前保守拒绝。
- 文件指纹匹配不能保证所有 UI 语义不变；新版本仍应验收设置页、对话输入、代码显示等主要页面。

## 备份与恢复

默认目录为 `~/Library/Application Support/antigravity-chinese-localization/`，按目标路径隔离。原包按内容 SHA-256 命名，`current.json` 保存版本与汉化前后的指纹。备份在提交前创建并校验，归档用同目录暂存文件原子替换。重复应用不会关闭应用、写入归档或增加新的原包备份。

恢复要求当前版本、当前汉化包哈希和备份哈希全部匹配。官方已升级或文件被其他工具改动时，恢复停止，防止把旧版原包恢复到新版客户端。历史原包保留，不自动删除。

以前手动安装或其他工具安装的汉化，可识别为“已汉化”，但本工具不会伪造原版备份；没有本工具记录时无法用 restore 恢复。请使用原先保存的同版本原包，或重新安装官方客户端。

异常中断可能遗留状态目录中的 `lock`。确认没有本工具在运行后才能删除该空目录重试；不要并发运行，也不要让不同备份目录同时管理同一应用。备份与清单不能防御拥有同等本地写权限的恶意进程。

## 维护补丁与测试

为新版本建立指纹时，应从可信的原始安装包逐文件比较，更新原始/汉化后的哈希；不得仅放宽版本判断或绕过冲突。原始文件发生变化时，需要审查和适配翻译，而不是将旧文件覆盖过去。

```bash
node --test tests/safe-reapply.test.js tests/safe-cli.test.js
```

测试覆盖兼容升级、保留未知文件、恢复、幂等、损坏输入、资源与备份校验、并发锁、进程检查、提交前更新冲突及 Electron fuse。默认旧测试入口也包含上述新测试；上游原有问题不在此功能中顺便修复。
